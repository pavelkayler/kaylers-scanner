Support

Kayler's Scanner: scan QR codes and barcodes into lists and export them to Excel.

Getting started

  1. Tap Scan and point the camera at a QR code or barcode. Each new code is saved at once; the camera stays open for the next one.
  2. After each scan the scanner waits a moment before reading the next code (3 seconds by default; change it in Settings).
  3. Tap Export to Excel to share the list as an .xlsx file, or Copy codes to paste them as plain text.
  4. New list starts another list; earlier lists stay in My lists.

Device names

In Device catalog, a rule gives codes a device name: INV-LT* means "starts with INV-LT", *LT* "contains LT", and a code without an asterisk must match exactly. You can also tap "+ name" next to a scanned code. The catalog can be exported to Excel and imported on another phone.

Backups and moving to another phone

Your lists are stored only on your phone. Use My lists → Save backup from time to time and keep the file in Files. To restore, use Restore from a backup: you see a preview first, and only lists and codes the phone does not have yet are added.

Moving from the web version to the iOS app (or between phones) works the same way: save a backup in one, restore it in the other. Their storage is separate.

Common questions

The camera does not start. Allow camera access: Settings → Apps → Kayler's Scanner → Camera (web version: Settings → Apps → Safari → Camera). You can always type a code by hand.

A code is not added. A code that is already in the open list shows "Already in list" and is not added twice. The same code held in front of the camera is read once.

I deleted a code by mistake. Tap Undo within 10 seconds.

The app says it could not save data. The phone's storage may be full. Save a backup right away, free some space, then continue.

Which version do I have? It is shown in About (at the bottom of the main screen).
