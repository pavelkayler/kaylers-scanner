# Тесты Kayler's Scanner

Запуск (нужен Node 18+):

    cd tests
    npm install
    npx playwright install chromium   # один раз, если Chromium для Playwright ещё не скачан
    npm test

- `fuzz-common.test.js`: фазз-тесты общих функций (шаблоны справочника, Excel-файлы, имена файлов) на сотнях случайных входных данных.
- `fuzz-app.test.js`: фазз-тесты настоящего приложения в Chromium: случайные и испорченные файлы резервной копии, случайное и повреждённое сохранённое состояние, запуск без сети.
- `invariant-app.test.js`: инвариантные тесты: случайные цепочки действий пользователя (сканы, списки, справочник, Excel, резервная копия, перезапуск), после каждого шага проверяются правила, которые не должны нарушаться.

Больше прогонов: `FUZZ_RUNS=5000 FUZZ_APP_RUNS=300 INVARIANT_RUNS=300 INVARIANT_STEPS=60 npm test`.
